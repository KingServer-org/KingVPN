## 🇮🇷 معرفی فارسی

KingVPN نرم‌افزار اختصاصی KingServer برای اندروید است. امکانات برنامه شامل مدیریت کانفیگ‌های سازگار با Xray، واردکردن از لینک و QR، ویرایش تنظیمات اتصال، رابط فارسی و انگلیسی و بررسی آپدیت از GitHub است.

دانلود APK رسمی پس از انتشار نخستین نسخه در بخش Releases فعال می‌شود. تنها فایل‌های منتشرشده توسط KingServer را نصب کنید.

## 🇬🇧 English Overview

KingVPN is KingServer's proprietary Android VPN client, offering Xray configuration management, QR and link import, editable connection parameters, a Persian/English interface and opt-in update checks.

**Android:** APK download will become available when the first official GitHub Release is published.

**iOS and Windows:** Coming soon.

## 🔐 Privacy & Safety | حریم خصوصی

Do not publish configuration links, tokens, credentials or UUIDs. Install only official KingServer APKs. No VPN can guarantee absolute anonymity.
